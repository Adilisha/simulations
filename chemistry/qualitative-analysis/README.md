# Tests for Common Cations

A standalone interactive qualitative-analysis simulation for identifying a classic classroom set and additional cations.

**Classic classroom set:** Ag+, Pb2+, Cu2+, Fe2+, Fe3+, Al3+, Zn2+, Ca2+, Ba2+, NH4+.

**Additional ions:** Co2+, Ni2+, Mn2+, Cr3+, Na+, K+, Sr2+.

**Advanced theory-only examples:** Hg2+, Cd2+, As3+. Mercury, cadmium, and arsenic compounds are highly toxic and are not suitable for routine classroom practicals. The sulfide-test observations are simulated only; do not perform these tests.

Open `index.html` in a modern browser. Choose a known cation to study its test reactions, or choose **Mystery unknown** to conceal the identity and practice identifying it. Add reagents, observe the precipitate, solution colour, or flame colour, and select your identification. Use **New sample / reset** to clear the observations; in mystery mode it also draws a different unknown.

The simulation presents simplified qualitative-test outcomes for learning and revision, not laboratory analytical reporting. Observations can depend on concentration, counter-ions, and experimental conditions.
