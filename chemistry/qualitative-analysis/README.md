# Tests for Common Cations

A standalone interactive qualitative-analysis simulation for identifying a classic school-lab set of cations:

- Ag+
- Pb2+
- Cu2+
- Fe2+
- Fe3+
- Al3+
- Zn2+
- Ca2+
- Ba2+
- NH4+

Open `index.html` in a modern browser. Choose a known cation to study its test reactions, or choose **Mystery unknown** to conceal the identity and practice identifying it. Add reagents, observe the precipitate or solution colour, and select your identification. Use **New sample / reset** to clear the observations; in mystery mode it also draws a different unknown.

The simulation focuses on common classroom tests and is intended for learning and revision, not analytical reporting.
