# Convex Lens Lab

An offline ray-diagram activity for a converging (convex) lens. Open `index.html` directly in a modern browser. No external dependencies or network access are required.

## Experiment

- Adjust object distance, focal length, and object height.
- The principal-ray diagram and image readings update as the sliders move. Animated dots travel along the rays; **Pause / Start** controls them.
- **Reset** returns to the starting setup. Use the header control to switch themes.

The simulation applies the thin lens equation, `1/f = 1/u + 1/v`, and magnification `m = −v/u`. Positive image distance indicates a real image on the far side of the lens; negative distance indicates a virtual image on the object's side. At `u = f`, the outgoing rays are parallel and the image is at infinity.
