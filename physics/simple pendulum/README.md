# Simple pendulum

This activity lets students explore how a pendulum moves and how the time period depends on its length and gravity.

## Controls

- String length: changes the pendulum length
- Start angle: changes the initial displacement
- Gravity: changes the gravitational field
- Pause / Play: starts or stops the motion
- Reset: returns the pendulum to its starting position

## Concept

The time period of a simple pendulum is:

T = 2π√(L / g)

where:
- T is the time period
- L is length of the pendulum
- g is gravitational acceleration

## How to use

Open `index.html` in a browser and adjust the sliders to observe the effect on the pendulum's motion.
