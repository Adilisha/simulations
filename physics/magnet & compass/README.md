# Magnet & Compass Lab

An interactive browser simulation for exploring how a bar magnet's magnetic field affects compass needles.

## Run the simulation

No installation or build step is required. Open `index.html` in a modern web browser.

Keep all three application files in the same folder:

- `index.html` — page structure and controls
- `styles.css` — layout, colors, and responsive styling
- `script.js` — canvas drawing, magnetic-field calculation, and interactions

## Use the controls

- Drag the magnet or any compass to move it.
- Use the **Magnet angle** slider or **Rotate** button to rotate the magnet.
- Adjust **Magnet strength** to change the field display.
- Select **Add compass** to add compasses (up to five total).
- Select **Reset** to restore the initial setup.

The red end of each compass needle points in the calculated field direction. The field visualization is a simplified educational model, rather than a precision physics measurement.

## Technologies

HTML, CSS, and vanilla JavaScript using the browser's Canvas API. No external libraries or packages are required.
