# Earth Science

Explore interactive simulations that help make Earth science ideas easier to understand. Experiment with each model, observe the results, and learn at your own pace.

## Practicals

- [Orbit Lab — Astronomy](astronomy/index.html): investigate orbital shape, distance, speed, and period.
- [Climate Balance — Climate Science](climate/index.html): explore how solar input, reflectivity, and greenhouse trapping affect temperature.
- [Moving Plates — Geology](geology/index.html): compare convergent, divergent, and transform plate boundaries.

Each practical is a standalone browser experience with no external dependencies. Open its `index.html` file to begin.
